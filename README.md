# Clinical References & Bedside Guides

A portal of curated quick-reference cards and decision-support tools for acute neurology, vascular stroke, and neurocritical care — NIHSS, TOAST, DAPT, EVT/IVT eligibility, HINTS, pupillometry, and more.

**Live:** https://rkalani1.github.io/clinical-references/

> Educational references only — not medical advice. Always confirm against current guidelines and local protocols before applying to patient care.

## Structure

Each topic lives in its own directory (e.g. `nihss/`, `toast/`, `evt/`, `ivt/`, `hints/`), linked from the `index.html` portal.
